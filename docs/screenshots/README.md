# Screenshots

Five shots carry the whole product. Each one should answer a question someone
has before they install anything.

| File | What it has to show | Why it earns its place |
|---|---|---|
| `rail-open.png` | The rail expanded, question list running top to bottom, a couple of document markers among them | This is the product. One image, one idea: your whole thread as a list |
| `hover-card.png` | The preview card up, heading pinned, a long prompt mid-scroll | Answers "the labels are truncated, so is this actually usable" |
| `search.png` | The `Alt+K` palette open with a query typed, results from more than one thread, the coverage line at the bottom | The only feature nobody guesses is there |
| `usage.png` | The header meters: model, effort, session and weekly bars with the elapsed marker | The reason people install a counter in the first place |
| `cowork.png` | A Cowork session with its outputs anchored between questions | Nobody else does this, and it is the hardest-won part |

## Framing

- 1440px wide or wider, then downscale. A 900px capture of a 22px rail reads as mush
- Dark theme. Claude is dark by default for most people and the rail was designed against it
- Crop to the right two-thirds. The empty left half of a chat window carries nothing
- Keep the browser chrome out. It dates the image and adds nothing

## Before committing any of these

These are screenshots of a real logged-in account in a public repository. Check
each image for anything you would not put on a billboard: thread titles,
question text, filenames, project and organisation names, plan percentages.

Redact in the image itself, not with CSS at capture time. A blur that lives only
in the screenshot cannot be undone by someone re-running the page.
